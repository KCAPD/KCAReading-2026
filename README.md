# KCAreading — Release 5.0

Upload these files to the root of the `KCAReading-2026` repository.

This release includes:
- coloured KCA value pills beneath every book;
- support for more than one value per book;
- a 2 × 2 “How it works” layout on phones;
- a centred “Brilliant reading” star on phones;
- cache-busted CSS and JavaScript references (`?v=50`);
- Google Form placeholders ready to replace in `books.js`.

The website also requires the existing `covers` folder containing `book-01.webp` through `book-80.webp`.
